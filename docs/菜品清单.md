## 二、菜单管理里自己加的菜（数据）

这类菜**不用改代码**：在「我的 → 菜单管理 → 加菜」里填就行，存进本机缓存并自动同步到云端。

| 步骤 | 说明 |
| --- | --- |
| 1 | 菜单管理 → 加菜，填菜名 / 分类 / 辣度 / 耗时 / 难度 / 标签 / 一句话介绍 / 食材 / 做法 |
| 2 | 封面图点「拍照 / 从相册选一张」，会自动压缩后上传云存储 |
| 3 | 保存 → 自动 `pushMenu` 推到云端，她那台下拉刷新就同步过去 |

> **图片为什么她也能看到**：云存储默认是「仅创建者可读写」（免费环境改不了），
> 所以链接由云函数 `imageUrls` 以管理员身份签发带签名的 https 链接，渲染前替换，缓存 25 分钟。

## 四、加图的标准流程

1. 你拍一张（或发我原图），**一道菜只挂一张封面**。
2. 我压到 900px 宽、150KB 以内，存成 `assets/dishes/dish-0X.jpg`。
3. 挂到 `data/dishes.js` 对应菜品的 `image` 字段，写成 `/assets/dishes/dish-0X.jpg`。
4. 你点「编译」看效果；要让她的手机也更新，重新「上传」体验版并在她手机上更新一次。
